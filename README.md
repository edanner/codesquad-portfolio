# CodeSquad Portfolio — Eric

Personal portfolio site for the CodeSquad course challenge. Built with plain HTML, CSS, and JavaScript — no frameworks.

## What's inside

- `index.html` — semantic structure (header, about, assignments gallery, footer)
- `style.css` — custom styling with dark/light themes
- `script.js` — theme toggle with saved preference + dynamic time-of-day greeting
- `images/` — assignment screenshots (placeholder SVGs — replace with real screenshots)

## Replacing the screenshots

Save your real screenshots into `images/` and update the three `<img src="...">` paths in `index.html` (or name your files `assignment-1.png` etc. and update the `src` attributes accordingly).

## Deploying to GitHub Pages

```bash
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main
```

Then on GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**. Your site goes live at `https://edanner.github.io/<repo-name>/`.
